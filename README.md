# FITLOG

**FITLOG** is a modern fitness and workout management web application that helps users explore exercises, build a personalized workout plan, save exercises for later, and track completed workouts.

## Technologies Used

- **Next.js** – React framework for building the application
- **React** – Component-based user interface
- **Tailwind CSS** – Responsive and modern styling
- **DaisyUI** – UI components
- **React Icons** – Icons throughout the application
- **React Toastify** – User notifications and alerts
- **REST API** – Fetching exercise data from an external API

## Key Features

1. **Exercise Library**
   - Browse a collection of exercises with details such as muscle groups, equipment, difficulty, sets, reps, duration, and calories burned.

2. **Exercise Details**
   - View detailed information and step-by-step instructions for each exercise.

3. **Personal Workout Plan**
   - Add exercises to today's workout plan and manage your selected exercises from the **My Plan** page.

4. **Save for Later**
   - Save exercises for later and access them from the **Saved** tab.

5. **Workout Tracking**
   - Mark exercises as completed, remove exercises from your plan or saved list, and view workout statistics such as total exercises, duration, and calories.
